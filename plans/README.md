  verification baseline every other risky change leans on. The repo currently has **no
  app-code test runner** — only data validators under `scripts/validate/`. Land 001 first

## Findings considered and rejected (so they are not re-audited)

- **Division-by-zero in `council-averages.ts:43`** — REJECTED. The `withSpending` filter at
  lines 38–41 guarantees population is truthy before the divide; the `|| 1` fallback is dead
  defensive code, not a live bug.
- **Postcode-lookup stale state in `SearchCommand.tsx:97-136`** — REJECTED. The
  `AbortController` returned from the effect aborts the in-flight fetch on query change /
  unmount; an aborted fetch rejects (handled in `.catch`, which ignores `AbortError`) rather
  than resolving, so no stale `setState` fires.
- **Comment UPDATE RLS "too strict" (`security-migration.sql:81-91`)** — REJECTED. Misread:
  the `WITH CHECK` locks `author_id`/`proposal_id`/`parent_id`/`flag_count`/`status` to their
  current values but leaves `body`/`edited_at` free to change, so editing works as intended.
- **Embed `postMessage(..., '*')` in `EmbedAutoResize.tsx`** — REJECTED as a top finding.
  A public embeddable widget cannot know the (arbitrary third-party) parent origin, and it
  only posts a height integer; `'*'` is the conventional, low-risk choice here.
- **`ResizeObserver`/`MutationObserver` cleanup in `EmbedAutoResize.tsx`** — REJECTED. React
  guarantees `useEffect` cleanup runs on unmount; the observers are disconnected.
- **CI placeholder env vars (`ci.yml:79-81`)** — REJECTED. By design and documented in the
  workflow: CI builds with non-functional placeholders; real values inject at Vercel runtime.
- **Decorative `w-8 h-8` icon containers flagged as sub-44px tap targets** — REJECTED. They
  are non-interactive presentational icons; the 44px minimum applies to touch targets.
- **Header icon-only buttons "missing aria-labels"** — REJECTED. The mobile toggles carry
  `aria-label="Toggle menu"` and the nav has `aria-label="Main navigation"`. (One minor nit
  remains: the toggle lacks `aria-expanded` — noted, not planned.)
- **Stripe checkout "missing webhook"** — NOT A FINDING. The route creates a donation
  Checkout Session (£1–£500, "Support CivAccount"); nothing is fulfilled or granted on
  payment, so no webhook is required. The route is CSRF-checked, rate-limited, and pins
  success/cancel URLs to the production origin. Verified sound.
- **Benford / YoY / last-verified statistical validators are scaffolds, not wired into
  `validate.mjs`** — NOT A FINDING. `ROADMAP.md` Phase E explicitly tracks these as future
  work; the files are marked `Status: SCAFFOLD`. This is planned, not drift.

## Table findings not turned into plans (lower leverage — recorded for later)

- **Median off-by-one on even-length arrays** (`insights-stats.ts:111` and `:334` —
  `sorted[Math.floor(len/2)]` returns the upper-middle instead of averaging the two middle
  values). Real but marginal (a few £ on public medians). **Folded into plan 001** as a
  covered test case + one-line fix.
- **Public API rate-limit doc drift** (README says "100 req/min", `developers/page.tsx`
  says 100 at lines 114/169/286, but `/api/v1/councils` list enforces 60). **Folded into
  plan 003.** (This is the exact item `../DATA-ACCESS-POLICY.md` Phase 3 flagged unfixed.)
- **Comment soft-delete is dead** — the committed comment `SELECT` RLS policy is
  `status='visible'` only (`supabase/schema.sql:113`); the fix to include `'removed'` is
  commented-out in `002_edit_delete.sql:33-36` and never applied by a later migration, so
  the "[Removed by author]" placeholder in `CommentThread.tsx` can never render. S effort,
  but it's a DB-migration task with unknown deployed-DB state — verify against production
  before writing a migration.
- **`email-digest` edge function** (`supabase/functions/email-digest/index.ts`) emails all
  users with no notification-preference / opt-out check and no per-invocation guard. Consent
  + spam surface; M effort. Requires service-role to invoke, so lower urgency.
- **CSP-report log forging** (`csp-report/route.ts:112-127`) — logged violation fields are
  not newline-stripped (unlike `clamp()` elsewhere), so a crafted report could forge log
  lines. Rate-limited 20/min/IP; LOW.
- **`/api/share/stat` renders arbitrary caller-supplied text** on a `civaccount.co.uk` OG
  card (minor brand/phishing surface). Rate-limited + CDN-cached; LOW.
